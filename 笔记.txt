MCP: 一套让 AI Agent 统一连接外部工具和数据源的协议。MCP 提供统一规范。
Agent 只需要实现一个 MCP 客户端，就能连接不同 MCP Server。
MCP 用于连接外部系统，让 Agent 能真正执行操作，例如：

查询数据库
调用 GitHub
操作浏览器
读取远程文件
发送消息
MCP Server 会通过 tools/list 告诉 Agent 有哪些工具，再通过 tools/call 执行工具。
tools/list 即服务端自己定义的函数

这个项目中实现了最小完整MCP工具链

1. initialize
客户端与服务器协商：

MCP 协议版本
客户端能力
服务器能力
客户端和服务器信息
服务器必须在响应中声明自己支持工具：

{
  "capabilities": {
    "tools": {}
  }
}
2. notifications/initialized
客户端通知服务器：

初始化已经完成，可以开始正常通信。

这是 JSON-RPC 通知，服务器不需要返回响应。

3. tools/list
客户端获取服务器提供的工具列表，通常包含：

工具名称
工具说明
输入参数结构 inputSchema
{
  "tools": [
    {
      "name": "add",
      "description": "计算两个数字之和",
      "inputSchema": {
        "type": "object",
        "properties": {
          "a": {"type": "number"},
          "b": {"type": "number"}
        },
        "required": ["a", "b"]
      }
    }
  ]
}
4. tools/call
客户端调用具体工具：

{
  "name": "add",
  "arguments": {
    "a": 10,
    "b": 20
  }
}
服务器返回工具执行结果。
